Colorizing the Prokudin-Gorskii Glass Plates

This project reconstructs color images from stacked grayscale negatives by splitting the three channels, aligning them with either a single-scale search or a coarse-to-fine pyramid, and then composing the final RGB result.

Single-scale alignment Pyramid alignment GitHub Pages gallery
Task

Split and align stacked channels

The input image contains the blue, green, and red exposures stacked vertically. The notebook first splits the scan into three equal parts, trims the borders, and then searches for the best translation that aligns the green and red channels to blue.

Strategy

Use single-scale for small scans, pyramid for large scans

The three special images, cathedral, monastery, and tobolsk, are shown as single-scale results. The remaining images use the pyramid method because the displacement is larger and the full-size scans are more expensive to search directly.

Presentation

Compare methods side by side

The test set is displayed row by row so you can compare the signal aligner result and the pyramid result for the same image immediately. The layout mirrors the project-webpage style expected for CS180: concise explanation, grouped sections, and image-first presentation.

Part 1

Final Results

The three low-resolution examples at the top were aligned using a single-scale signal aligner. The rest of the gallery uses the pyramid pipeline, which is better suited to the large TIFF scans and larger displacements. Border pixels are ignored during scoring so that the wrap-around artifacts from shifting do not affect the match.

Part 2

Test Results

For the test images, each row shows the same input processed by two methods. This makes it easy to compare whether the signal aligner is already sufficient or whether the pyramid method produces a cleaner final alignment.
